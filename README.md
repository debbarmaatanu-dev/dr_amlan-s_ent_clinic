Official website for Dr. (Major) Amlan's ENT Clinic, providing comprehensive ear, nose, and throat care services in Agartala, West Tripura.

## 🏥 About

Dr. (Major) Amlan's ENT Clinic offers expert, patient-focused ENT care with:

- Comprehensive ENT consultations
- Allergy testing and immunotherapy
- Endoscopic and microscopic ENT procedures

## 🛠️ Technology Stack

- **Frontend Framework:** React 19.2.0 with TypeScript

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/AtanuDebbarma/btcstagartala.git

# Navigate to project directory
cd dr_amlan-s_ent_clinic

# Install dependencies
npm install
```

### Development

```bash
# Start development server
npm run dev

# Run linting
npm run lint

# Format code
npm run format

# Build for production
npm run build

# Preview production build
npm run preview
```
